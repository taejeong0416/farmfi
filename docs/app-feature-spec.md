## 1. 프로젝트 개요
---
### 한 줄 정의
스마트팜 상가 운영 앱

### 제품 목표
스마트팜 기반 상가의 운영자가 재배, 설비, 재고, 매출 정보를 모바일에서 통합 관리하고 현장 대응 시간을 줄이도록 돕는다.

### 배경
운영자는 여러 재배 베드와 매장을 관리하면서 생육 상태, 환경 센서, 재고, 판매 현황을 서로 다른 방식으로 확인해야 한다. 제공된 화면 구성은 운영자가 매장 단위로 주요 현황을 빠르게 확인하고 조치할 수 있는 모바일 관리 환경을 지향한다.

### 사용자 문제
스마트팜 상가 운영자는 재배 상태와 설비 이상, 재고 부족, 매출 변화를 실시간으로 한눈에 파악하기 어렵다. 현장 설비를 확인하거나 운영 데이터를 취합하는 데 시간이 걸려 대응이 늦어질 수 있다.

### 해결 방안
매장 선택 기반의 모바일 앱에서 대시보드 요약, 작물 생육 관리, 베드별 센서 모니터링과 설비 제어, 재고 관리, 판매 리포트를 제공한다. 중요 알림과 상세 화면을 연결해 운영자가 확인부터 조치까지 빠르게 처리하도록 한다.

### 차별점
재배 환경 데이터와 매장 운영 데이터인 재고·매출을 하나의 운영 화면 흐름으로 연결한다. 베드 단위의 시각적 모니터링과 모바일 현장 제어를 함께 제공해 복수 매장 운영에 적합하게 만든다.

### 타겟 사용자
스마트팜 기반 상가를 운영하거나 여러 매장의 재배·판매 운영을 관리하는 매장 운영자이다. 모바일로 현장을 확인하며 재배 베드, 설비 상태, 재고, 판매 실적을 빠르게 판단하고 조치해야 한다.

### 사용자 시나리오
운영자는 앱에 로그인해 관리할 매장을 선택하고 대시보드에서 재배 상태, 설비 알림, 재고, 매출 요약을 확인한다. 이상 알림이 있으면 해당 베드의 센서와 설비를 확인·조작하고, 재배 일정과 생육 기록을 관리한다. 재고 부족을 조정하거나 판매 리포트와 거래 내역을 확인해 운영 결정을 내린다.

### 핵심 지표
주간 활성 운영자 비율, 운영자 1인당 주간 현황 조회 횟수, 설비 알림 확인 및 조치 시간, 재고 부족 발생 건수, 리포트 조회·내보내기 횟수를 추적한다.

### 리스크
센서 데이터 또는 설비 제어 연동이 지연·실패하면 현장 운영 판단에 영향을 줄 수 있다. 재고와 매출 데이터의 동기화 오류, 역할별 권한 관리 미흡, 모바일 네트워크 불안정도 주요 리스크이다.

### 카테고리
> 커머스 / 쇼핑

### 사용자 역할
> 매장 운영자, 관리자

### 디바이스 (기기)
> 모바일 앱

## 1. 인증 및 매장 접근
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

매장 운영자와 관리자는 계정으로 앱에 인증하고 자신에게 허용된 운영 매장을 선택해 관리 업무를 시작한다. 이 영역은 로그인, 로그아웃, 매장 전환과 접근 가능한 매장 목록을 포함하며 계정 생성 절차는 포함하지 않는다.

**수용 기준:**
```
1. ○ 유효한 계정 정보로 로그인하면 운영 가능한 매장 선택 화면으로 이동한다.
2. ○ 사용자는 권한이 있는 매장 목록에서 한 매장을 선택해 대시보드로 이동할 수 있다.
3. ○ 로그아웃을 확인하면 현재 세션이 종료되고 로그인 화면으로 이동한다.
```


### 1.1 로그인 및 매장 선택
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

매장 운영자는 계정으로 로그인한 뒤 권한이 있는 운영 매장 중 하나를 선택해 앱을 시작한다. 이 기능은 로그인과 매장 선택을 포함하며 계정 가입과 비밀번호 재설정은 포함하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 사용자는 등록된 계정과 하나 이상의 접근 가능 매장을 보유한다.
- **트리거**: - 사용자가 앱을 실행하거나 로그아웃 후 로그인 화면에 진입한다.
- **동작**: - 시스템은 계정 정보를 검증하고 접근 가능한 매장 목록을 조회한다.
  - 사용자가 매장을 선택하면 해당 매장을 현재 운영 매장으로 설정한다.
- **결과**: - 인증 성공 시 선택한 매장 기준의 대시보드를 표시한다.
- **표시**: - 로그인 화면에는 계정 정보 입력 영역과 로그인 버튼을 표시한다.
  - 매장 선택 화면에는 접근 가능한 매장 목록을 표시한다.
- **권한 & 접근**: - 비로그인 사용자는 로그인 화면만 이용할 수 있다.
  - 사용자는 권한이 부여된 매장만 선택할 수 있다.
- **데이터**: - 사용자 계정은 사용자 식별자와 인증 정보를 가진다.
  - 매장 접근 권한은 사용자와 매장의 관계로 저장한다.

## 2. 운영 대시보드 및 알림
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 선택한 매장의 재배 상태, 설비 알림, 재고, 매출 요약을 대시보드에서 확인한다. 이 영역은 알림 확인과 매장 전환 진입을 포함하며 각 관리 데이터의 상세 편집은 개별 관리 영역에서 처리한다.

**수용 기준:**
```
1. ○ 선택한 매장 기준의 재배, 설비, 재고, 매출 요약이 대시보드에 표시된다.
2. ○ 운영자는 대시보드에서 설비 알림 상세 목록으로 이동해 알림을 확인 처리할 수 있다.
3. ○ 운영자는 대시보드에서 다른 운영 매장으로 전환할 수 있다.
```


### 2.1 운영 현황 대시보드
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 선택한 매장의 재배 상태, 설비 알림, 재고, 매출 요약을 한 화면에서 확인한다. 이 기능은 현황 요약과 상세 화면 진입을 제공하며 데이터 편집은 각 관리 기능에서 수행한다.

**개발 준비 슬롯**
- **선행조건**: - 사용자는 로그인하고 운영 매장을 선택한 상태이다.
- **트리거**: - 사용자가 대시보드 탭을 선택하거나 매장 선택을 완료한다.
- **동작**: - 시스템은 선택한 매장 기준의 재배, 설비, 재고, 매출 요약 데이터를 조회한다.
- **결과**: - 대시보드에 최신 운영 요약과 상세 화면 진입점을 표시한다.
  - 대시보드 조회 이벤트를 기록한다.
- **표시**: - 재배 상태, 설비 알림, 재고, 매출을 카드 형태로 표시한다.
  - 데이터 조회 중에는 각 카드에 로딩 상태를 표시한다.
- **권한 & 접근**: - 사용자는 선택한 매장의 요약 데이터만 확인할 수 있다.
- **데이터**: - 운영 요약은 매장 식별자, 집계 시각, 재배·설비·재고·매출 요약값으로 구성한다.


### 2.2 설비 알림 확인
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 설비 이상과 주의 알림의 상세 내용을 확인하고 처리 완료로 표시한다. 이 기능은 알림 조회와 확인 처리를 포함하며 설비 원인 분석은 포함하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 선택한 매장에 설비 알림이 존재할 수 있다.
- **트리거**: - 사용자가 대시보드의 설비 알림 요약 또는 알림 상세 진입점을 선택한다.
- **동작**: - 시스템은 매장별 설비 알림 목록을 조회한다.
  - 사용자가 알림을 확인 처리하면 처리 시각과 처리자를 기록한다.
- **결과**: - 알림의 확인 상태가 갱신되고 대시보드 알림 요약에 반영된다.
- **예외**: - 이미 확인된 알림을 다시 확인 처리해도 상태를 중복 변경하지 않는다.
- **표시**: - 알림 목록에 발생 시각, 대상 베드 또는 설비, 심각도, 확인 상태를 표시한다.
- **권한 & 접근**: - 접근 권한이 있는 매장의 알림만 조회하고 확인 처리할 수 있다.
- **데이터**: - 설비 알림은 알림 식별자, 매장·베드·설비 식별자, 심각도, 발생·확인 시각, 확인자 정보를 가진다.

## 3. 재배 및 생육 관리
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 작물과 베드별 생육 현황을 확인하고 생육 기록 및 재배 일정을 관리한다. 이 영역은 작물 생육 정보와 파종·수확 일정의 등록을 포함하며 자동 생육 예측은 포함하지 않는다.

**수용 기준:**
```
1. ○ 운영자는 작물별 생육 현황 목록과 작물의 생육 단계·이력을 확인할 수 있다.
2. ○ 운영자는 작물의 생육 기록을 입력하고 저장할 수 있다.
3. ○ 운영자는 파종·수확 일정을 등록하고 일정 목록에서 확인할 수 있다.
```


### 3.1 작물 생육 현황 조회
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 작물과 베드별 생육 현황, 생육 단계, 기록 이력을 조회한다. 이 기능은 현황 조회를 포함하며 생육 기록의 입력은 별도 기능으로 처리한다.

**개발 준비 슬롯**
- **선행조건**: - 선택한 매장에 재배 중이거나 기록이 있는 작물이 존재한다.
- **트리거**: - 사용자가 운영 탭에서 작물 또는 베드 항목을 선택한다.
- **동작**: - 시스템은 작물별 생육 현황과 선택한 작물의 생육 단계·이력을 조회한다.
- **결과**: - 사용자가 작물별 생육 상태와 기록 이력을 확인할 수 있다.
- **예외**: - 조회 가능한 작물이 없으면 빈 상태를 표시한다.
- **표시**: - 작물 목록에는 작물명, 배정 베드, 생육 단계, 생육 상태를 표시한다.
  - 상세 화면에는 생육 단계와 기록 이력을 시간순으로 표시한다.
- **권한 & 접근**: - 사용자는 선택한 매장의 작물 생육 정보만 조회할 수 있다.
- **비즈니스 규칙**: - 생육 기록 이력은 최신 기록부터 표시한다.
- **데이터**: - 생육 기록은 작물·베드 식별자, 기록 시각, 생육 단계, 관찰 내용, 작성자 정보를 가진다.


### 3.2 생육 기록 및 재배 일정 관리
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 작물의 생육 기록을 저장하고 파종·수확 일정을 등록해 재배 계획을 관리한다. 이 기능은 수동 기록과 일정 등록을 포함하며 자동 일정 추천은 포함하지 않는다.

**개발 준비 슬롯**
- **선행조건**: - 사용자는 선택한 매장과 대상 작물 또는 베드를 선택한 상태이다.
- **트리거**: - 사용자가 생육 기록 저장 또는 재배 일정 추가를 선택한다.
- **동작**: - 시스템은 입력값을 검증하고 생육 기록 또는 재배 일정을 저장한다.
- **결과**: - 저장된 생육 기록은 작물 이력에 반영된다.
  - 저장된 재배 일정은 일정 목록에 표시된다.
- **예외**: - 필수 입력값이 없으면 저장하지 않고 입력 오류를 안내한다.
- **표시**: - 기록 및 일정 입력 화면에 필수 항목과 저장 결과 메시지를 표시한다.
- **권한 & 접근**: - 매장 운영자와 관리자는 접근 가능한 매장의 기록과 일정을 등록할 수 있다.
- **데이터**: - 재배 일정은 일정 식별자, 매장·작물·베드 식별자, 파종일, 수확 예정일, 상태를 가진다.

## 4. 스마트팜 모니터링 및 제어
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

운영자는 베드별 환경 센서와 설비 상태를 모니터링하고 필요한 설비 제어와 임계값 설정을 수행한다. 이 영역은 실시간 현황, 기간별 센서 이력, 제어 결과 확인을 포함하며 설비 자동 제어 정책의 설계는 포함하지 않는다.

**수용 기준:**
```
1. ○ 운영자는 베드를 선택해 온도, 습도, CO₂, EC와 설비 제어 현황을 확인할 수 있다.
2. ○ 운영자는 허용된 설비 제어를 실행하고 성공 또는 실패 결과를 확인할 수 있다.
3. ○ 운영자는 센서 이력 그래프를 조회하고 센서 임계값을 저장할 수 있다.
```

### 5.1 재고 현황 및 조정

운영자는 품목별 현재 재고와 입출고 이력을 확인하고 재고 수량을 조정한다. 이 기능은 재고 현황과 수동 조정을 포함하며 구매 발주 처리는 포함하지 않는다.

**개발 준비 슬롯**

- **결과**: - 변경된 재고 수량과 조정 이력이 저장된다.

- **표시**: - 재고 목록에는 품목명, 현재 수량, 부족 상태를 표시한다.

- **권한 & 접근**: - 매장 운영자와 관리자는 접근 가능한 매장의 재고를 조회한다.

- **데이터**: - 재고 품목은 품목 식별자, 매장 식별자, 품목명, 현재 수량, 단위, 부족 기준 수량을 가진다.

**개발 준비 슬롯**
- **선행조건**: - 사용자는 로그인한 상태이다.
- **트리거**: - 사용자가 설정 화면에서 로그아웃을 선택한다.
- **동작**: - 시스템은 로그아웃 확인을 받은 뒤 현재 인증 세션을 종료한다.
- **결과**: - 현재 기기의 인증 정보가 제거되고 로그인 화면으로 이동한다.
- **예외**: - 로그아웃 처리 요청이 실패해도 로컬 인증 정보를 제거하고 로그인 화면으로 이동한다.
- **표시**: - 로그아웃 전에 확인 메시지를 표시한다.
- **권한 & 접근**: - 로그인한 사용자는 자신의 세션을 종료할 수 있다.
- **비즈니스 규칙**: - 로그아웃 취소 시 현재 화면과 세션을 유지한다.
- **데이터**: - 현재 기기의 인증 세션 정보는 로그아웃 시 삭제한다.

# FarmFi — 토큰증권(STO) 활용 미니팜 자금집행 웹플랫폼

> 도심 유휴 상가를 스마트팜 기반 신선식품 매장으로 바꾸고, 그 전환 자금을 STO로 조달하며, 스마트컨트랙트 에스크로가 자금 집행을 다중 신호 검증에 연동해 단계 집행하는 플랫폼.

**투자자에게 하는 한 문장** — "당신은 매장 한 곳의 설비에 이웃과 함께 투자하고, 검증 결과에 따라 코드가 자금을 단계 집행하며, 매장이 파는 만큼 투자 비율대로 매달 배당을 받는다."

> **본 문서의 전제 가정 (명시)** — 아래 사항이 농관원·한전 확인을 통과했다고 가정한다: ① 운영자당 인근 2사이트 바닥면적 합산(165.2㎡) 또는 "연간 판매액 120만원 증명" 경로로 **농업경영체 등록 성공**, ② **농사용 전력(을) 적용** (일반 전기의 약 1/3 단가), ③ 운영자의 **청년후계농 정착지원금**(월 90~110만, 3년) 수급. 이 가정의 확인 절차는 §10 참조.

---

## 1. 문제

| 주체 | 문제 |
|---|---|
| 도시 | 부산대 상권 공실률 23.4% — 부산 중대형(15.3%)·전국 평균(14.1%)을 모두 웃돌며 3년째 회복되지 않는다 |
| 운영자 | 스마트팜 창업은 설비 자본이 진입장벽 |
| 투자자 | 조각투자 시장은 "고수익 홍보 → 자금 유용·부실 검증" 신뢰 문제가 반복 |

세 문제의 교차점: **자본은 검증을 요구하고, 검증은 코드로 강제할 수 있다.**

전환 업종은 세 조건을 동시에 충족해야 한다 — 인구 밀집 상권의 **입지**(반복 수요), 온라인으로 대체되기 어려운 **품목**(신선·즉시성), 좁은 공간에서 마진을 얻는 재배·판매 일체형 **구조**(공간 효율성). 스마트팜 기반 신선식품 매장이 이 셋을 모두 만족한다.

## 2. 구조 — 누가 무엇을 하고 돈은 어떻게 흐르나

```
[투자자] --STO(투자계약증권)--> [매장 에스크로 (스마트컨트랙트)]
                                   │ 4-마일스톤 검증마다 트랜치 집행
                                   ▼
                              매장 설비·시설·셋업

[기관/건물주]  유휴공간 제공 — 계약 주체는 운영자 개인 (무상~저가 유상)
[운영자]       매장 운영, 운영비 부담, 재배·수확·포장·판매 수행
               농업경영체 등록 → 농사용 전력 + 정착지원금 (전제 가정)
[FarmFi]       투자자 모집·운영자 모집·교육·셋업 + 재배-재고 연동 SW + B2B/체험 유치 대행

[정산]
  매장 매출 → 월 단위 집계 → 운영비 차감 → 순이익 분배
    · 투자자: 투자 지분 비율대로 매달 배당
    · 운영자: 잔여 수익 수령
    · FarmFi: 플랫폼 이용료·중개 수수료
```

핵심 프로세스는 여섯 단계로 순환한다.

```
① 생산 → ② 판매 → ③ 매출 발생 → ④ 정산 → ⑤ 참여자 회수 → ⑥ 재생산
```

스마트미니팜에서 작물을 생산하고, 24시간 무인매장과 인근 가게 B2B로 판매해 안정적 매출을 만든다. 월 단위로 매출과 운영비를 집계해 에스크로에서 조건별로 직접 분배하고, 회수된 자금이 지속 운영과 재투자로 돌아간다.

설계 원칙 세 가지:
1. **트랙 분리** — 투자금은 설비에만 닿는다. 운영자는 투자구조 밖의 독립 개인사업자로 남아 농업인 지위·정부지원 수급 자격을 유지한다.
2. **검증 없이 집행 없음** — 자금 집행은 사람의 승인이 아니라 다중 신호 검증 통과가 연다. 강제 통과 경로를 두지 않는다.
3. **정직한 공시** — 목표 수익률과 회수 기간은 달성 조건과 함께 제시하고, 미달 시나리오를 청약 자료에 함께 싣는다.

## 3. 투자 구조 — 매장 한 곳을 최대 10명이 나눈다

| 항목 | 조건 |
|---|---|
| 매장당 조달 | 1,750만원 |
| 1인 최소 청약 | 175만원 (최대 10명) |
| 배당 | 매장 매출에 연동, 투자 지분 비율대로 매달 지급 |
| 목표 회수 | 약 15개월(선택)에 원금 회수 + 연 12% 추가 수익 |
| 엑싯 | 원금 + 수익을 모두 회수하면 해당 투자자의 배당 종료 |

타깃은 "목돈은 없고 코인은 불안한, 실물 담보 있는 소액투자를 원하는" 30~40대 지역 직장인이다. 사이트 상권 반경 2km 주민·소상공인이 1차 타깃인 이유는 **투자자가 곧 단골이자 홍보자**이기 때문이다. 투자금이 마케팅을 겸한다.

### 단계별 투자와 토큰 가치

라운드는 매장의 상태에 따라 단계로 나뉜다. 흑자 전환까지 남은 시점이 짧아질수록 리스크가 줄고 토큰 가치가 오른다. 초기 진입 투자자가 우대되는 구조다.

| 단계 | 상태 | 리스크 | 토큰 가치 |
|---|---|---|---|
| 1단계 초기 구축 | 흑자 전환까지 먼 시점 | 가장 높음 | 가장 낮음 |
| 2단계 운영 검증 | 데이터 축적·입증 중 | 감소 시작 | 점진적 상승 |
| 3단계 흑자 근접 | 안정성 증가 | 감소 | 상승 가속 |
| 4단계 흑자 이후 | 반복 흑자·배당 가능 | 가장 낮음 | 가장 높음 |

### 마일스톤 트랜치 (매장당)

| 단계 | 집행 | 검증 신호 |
|---|---|---|
| ① 공간 준비 | 35% | 임대계약서 OCR + 시공 영수증 + 완공 사진 (교차검증) |
| ② 시운전·운영 안정 | 30% | 센서 데이터 가동률 |
| ③ 첫 수확·판매 | 20% | 수확 사진 + 판매 영수증 |
| ④ 지속 운영 | 15% | 센서 데이터 + 복수 판매 영수증 |

각 마일스톤에는 180일 데드라인이 있고, 경과 시 **누구나 실패 전환을 트리거해 환불 모드로 넘길 수 있다** — 운영사의 선의에 의존하지 않는 투자자 탈출구.

**파일럿 라운드**는 1호점(25평 표준 유닛)을 단독 모집·구축·실증하고, 실측 지표(전기요금·판매율·단가)를 공개한 뒤에만 사이트 2~5를 순차 모집한다. 온체인 게이트(RoundGate 컨트랙트)가 순차 개설을 코드로 보증한다 — 1호점이 전 마일스톤을 통과하기 전에는 나머지 사이트의 자금 집행이 열리지 않고, 1호점 실패 시 나머지 투자금은 미집행 전액 환불된다. 운영자 기본형은 인근 2사이트 운영으로, 소득 2배와 바닥 합산 165.2㎡의 농업경영체 면적 기준을 동시에 충족한다.

## 4. 유닛 이코노믹스 — 3-시나리오 (운영자 기본형 = 2사이트, 농사용 전력 적용)

전제: 사이트당 월 500포기 × 3,500원, 체험 회당 30만원(운영자 70/FarmFi 30, 사이트당 월 4/2/1회), 농사용 전력으로 전기 사이트당 17/25/33만.

**운영자 월 손익 (2사이트 합산)**

| | 낙관 | 중립 | 보수 |
|---|---|---|---|
| 매출 (판매율 100/80/70%) | 350만 | 280만 | 244만 |
| 체험 70% | +168만 | +84만 | +42만 |
| 운영비 (농사용 전기 + 자재) | −124만 | −140만 | −156만 |
| 이용료 (20만×2) | −40만 | −40만 | −40만 |
| 임대료 (무상/저가) | 0 | −50만 | −50만 |
| 투자자 배당 (매출 연동) | −56만 | −45만 | −39만 |
| **사업소득** | **+298만** | **+89만** | **+1만** |
| 정착지원금 (개인, 1년차) | +110만 | +110만 | +110만 |
| **실질 소득** | **408만** | **199만** | **111만** |

- **중립 199만** 수준의 소득이 성립한다. 농업경영체 등록(전제 가정)이 만드는 차이는 크다 — 농사용 전력으로 운영비가 사이트당 월 33~67만 절감되고, 지원금이 3년 초기를 받친다.
- 지원금 종료(4년차) 이후의 자립은 고부가 작물 전환(단가 3,500 → 5,000원+)에 달려 있고, 이 단가·수율 달성이 1호점 게이트 통과 기준이다.
- 확장 옵션: 등록 성공 시 스마트팜 종합자금(금리 1%, 10억 이하 무담보) 접근 가능 — 운영자의 자가 확장 등 STO 밖 성장 경로.

**투자자 관점 (매장 1곳 기준)**

| 항목 | 값 |
|---|---|
| 매장 조달 | 1,750만 (10명 × 175만) |
| 배당 재원 | 매장 매출 연동 월 배당 |
| 목표 회수 | 약 15개월 원금 회수 + 연 12% 추가 수익 |
| 달성 조건 | 판매율 낙관 시나리오 유지 + 체험 프로그램 정상 가동 |
| 미달 시 | 배당은 매출에 연동되므로 회수 기간이 늘어난다. 원금 보장 상품이 아니다 |

- 배당이 매출에 연동되므로 **운영자 매출의 지속성이 곧 배당의 신용도**다. FarmFi가 재배 지원·B2B 유치·체험 중개에 이해관계를 갖는 이유가 여기 있다.
- 회수 기간 15개월과 연 12%는 낙관~중립 상단 시나리오의 목표치다. 보수 시나리오에서는 회수가 지연된다. §10에 이 수치의 취약점을 명시했다.

## 5. 타깃 투자자

| 순위 | 타깃 | 티켓 | 사는 이유 |
|---|---|---|---|
| 1차 | 매장 상권 반경 2km 지역 주민·소상공인 | 175만원~ | "내 동네 가게의 지분" + 투자자 멤버십(할인·체험 우선권). **투자자가 곧 단골·홍보자** |
| 2차 | 조각투자 경험 보유 3040 리테일 | 175만원~ | 새 실물 자산 클래스 + 코드 검증 투명성 |
| 3차 | 임팩트·ESG 개인/기관 | 수백만원~ | 파일럿 실증 지표 공개 후 |

**비타깃을 명시한다**: 15개월 내 확정 회수를 요구하는 투자자(배당은 매출 연동 변동), 원금 보장을 기대하는 투자자.

## 6. 토큰·상환 설계

- **토큰 = 매장 단위 수익분배권** (법인 지분 아님 — 뱅카우식 투자계약증권). 매장 간 분리로 이해충돌을 차단하고, 홀더에게 차기 라운드 우선 청약권을 준다.
- **배당**: 월 정산, 스냅샷 블록 기준 분배 (배당 발표 후 취득분은 해당 회차 청구 불가 — 컨트랙트 구현 완료).
- **엑싯**: 원금 + 목표 수익을 모두 회수한 투자자는 배당이 종료되고, 해당 지분은 다음 라운드 투자자에게 재배정된다. 2027.2 개정법 시행 후에는 장외 유통으로 중도 매각 경로가 추가된다.
- **미달 시 정직 공시**: 배당이 매출에 연동되므로 회수 기간은 확정되지 않는다. 보수 시나리오의 회수 기간과 설비 잔존가치(원가의 15~25%) 기준 청산 회수율을 청약 자료 첫 페이지에 싣는다. **원금 보장 상품이 아니다.**

## 7. 법·규제 — 조사로 확정한 사실

| 쟁점 | 결론 |
|---|---|
| 외부 투자 유치 시 정부지원 배제? | **배제 규정 없음.** TIPS·농식품부 스케일업은 오히려 투자 유치가 전제/가점 |
| 수직농장 농업경영체 등록 | 실무 기준 "바닥 재배면적 165㎡ 이상"(농관원 공식 홈페이지 게시) — **운영자당 2사이트 합산(165.2㎡)으로 충족** (전제 가정 ①). 대안: "연간 판매액 120만원 증명" 경로 |
| 청년후계농 정착지원금 | 개인만 가능 — 운영자를 투자구조 밖 개인사업자로 두는 우리 구조와 정합 (전제 가정 ③) |
| 보조금 자산 | 투자자 담보 불가(보조금법 35조) → 보조금 자산과 STO 자산 회계 분리 |
| 청약 자격 확인 | 실명·연령·투자한도 확인이 자본시장법상 의무 → OpenDID 모바일 신분증으로 자동 판별 (§8) |
| 발행 경로 | 자체 플랫폼 직접공모(정식 증권신고서, 뱅카우 선례)가 지향점. 발행비용은 라운드가 아닌 본체 부담이며, 초기 라운드는 증권형 크라우드펀딩(연 30억 한도)이 실질 경로일 수 있음 |
| 유통 | 현행법상 청산까지 보유 → **2027.2.4 시행 개정법으로 유통 개방** — 본 설계는 이 제도에 올라타는 선행 구현 |
| 체험·판매 인허가 | 직접 재배 원물 판매는 신고 불요. 체험은 가족·성인 원데이 중심(학교 정규 체험학습은 수탁 요건상 제외), 배상책임보험 가입 |

## 8. 기술 — 구현된 것

- **Polygon 테스트넷 실배포 스택**: Escrow(4-마일스톤 트랜치) + RoundGate(1호점 게이트) + Dividend(스냅샷 배당) + FarmToken(블록 체크포인트 + 신원 레지스트리)
- **AI 멀티시그널 검증**: 계약서·영수증 OCR + 현장사진 비전 + IoT 이상탐지(Z-score + 도메인 정상범위 판정), AND 조건·교차검증 — 통과 시 추가 승인 없이 온체인 자동 집행
- **신원 검증(OpenDID)**: OmniOne CX 표준인증창(QR/딥링크) → 전자지갑 신분증 제출(eVP) → VC·Verifier 검증 → JWT 파싱 → 실명·연령·투자한도 판별 → 청약 승인. 조폐공사 K-DID 공개 SDK 기반이며, Selective Disclosure로 실명·만 18세 이상·투자한도만 선택 추출한다. 지갑↔DID 해시를 토큰 컨트랙트 신원 레지스트리에 온체인 바인딩해 익명 지갑 문제와 증권 보유자 식별을 함께 푼다.
- **투자자 보호 3종**: 마일스톤 데드라인 타임아웃(누구나 트리거) / 미집행 잔여금 비례 환불 / 배당 스냅샷 — 전체 테스트 통과(퍼즈·불변식 테스트 포함)
- 표현의 정확성: 이 시스템은 **검증 가능한(verifiable) 자금 집행**이다. trustless는 외부 오라클·검증인 분산이 완성되는 로드맵 목표

**데모 흐름**: 신원인증 → 청약 → 에스크로 락업 → 계약서 OCR 검증 → 트랜치 자동 집행(tx 해시) → 검증 실패 케이스 차단 → IoT 검증 → 배당 스냅샷 분배 → 라운드 게이팅 시연.

## 10. 전제 가정의 확인 절차와 취약점

**전제 가정 확인 절차** (문서 첫머리 가정 ①~③의 검증 방법): 관할 농관원 지원·사무소 사전 문의(1644-8778, 사전진단 uni.agrix.go.kr)로 ① 떨어진 2구획의 바닥면적 합산 인정, ② 판매액 120만원 대체 경로 가부를 확인하고, 한전(1577-2700)에 도심 상가 실내팜의 농사용(을) 적용을 확인한다. 확인 결과가 부정적이면 §4의 수치는 일반 전기·지원금 제외 기준으로 재계산되어야 한다.

**우리가 아는 취약점** — 숨기지 않고 먼저 말한다:

1. **목표 수익률·회수 기간이 낙관 시나리오 기준** — 15개월 회수와 연 12%는 판매율이 낙관~중립 상단을 유지하고 체험 프로그램이 정상 가동될 때의 목표치다. 배당이 매출에 연동되므로 보수 시나리오에서는 회수가 지연된다. 이 수치는 확정 수익이 아니라 목표임을 청약 자료에 명시한다.
2. **운영자 유닛의 마진이 정책 지원에 기대는 초기 구조** — 중립 실질 199만 중 지원금이 110만(3년 한시). 4년차 자립은 고부가 작물 전환(단가 5,000원+)에 달려 있고, 이 단가·수율 달성이 1호점 게이트 통과 기준이다.
3. **배당이 운영자 소득을 압박할 수 있다** — 매출 연동 배당은 매출이 낮은 달에 운영자 몫을 줄인다. 보수 시나리오의 운영자 사업소득이 1만원 수준까지 내려가므로, 최저 운영자 소득선을 두는 배당 하한 장치가 필요하다. 파일럿에서 이 선을 실측으로 확정한다.
4. **핵심 수치 3개가 실측 전** — 전기요금(농사용 적용 폭), 설비비, 고부가 작물 수율. 전부 1호점 실증 게이트에서 확정되며, 확정 전 확장 모집은 열리지 않는다.
5. **체험 수요의 상한** — 지역 교육예산은 유한하고 방학이 있다. 체험을 확정 수익이 아닌 상방으로만 계상하고, 기업 팀빌딩·ESG 예산(별도 풀)으로 우회한다.
6. **검증의 중앙화** — 검증자 지정과 AI·IoT 데이터가 현재 FarmFi 소산이다. 타임아웃 탈출구로 자금 동결 리스크는 제거했지만, 검증 자체의 분산(외부 오라클·검증인)은 로드맵이다.
7. **발행비용 대 라운드 규모** — 정식 증권신고서 비용이 매장 단위 라운드에 과중할 수 있어 로펌 견적 확정 전까지 크라우드펀딩이 실질 경로다.
8. **전제 가정 자체의 리스크** — 본 문서는 농업경영체 등록·농사용 전력·정착지원금을 가정으로 두었다. 가정이 깨지면 운영자 실질소득이 급락하며, 이 경우의 대응은 고부가 작물 조기 전환이다. **가정 확인 전에는 §4 수치를 외부에 확정치로 제시하지 않는다.**

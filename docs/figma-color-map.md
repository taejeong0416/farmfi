# Figma 색 치환표

`design/*.fig`에 쓰인 색을 그라운드 룰 팔레트(`build-plan.md`)로 옮기는 표. 화면을 코드로 옮길 때 이 표를 대조한다.

집계는 잠정본 `.fig` 기준이다. 최종본이 오면 색이 새로 들어올 수 있어 이 표를 다시 뽑는다(`build-plan.md` Phase N).

집계 기준은 노드 수다. 웹 1,746개·앱 326개가 팔레트 밖 색을 쓰지만, 대부분은 브랜드 초록·회색의 명도 변종이라 톤만 통일하면 된다. 규칙을 실제로 어기는 것은 웹 94개·앱 21개다.

`#FAD61A`(카카오 노랑) `#1FB85C`(네이버 초록) `#2E5EDB` `#386BB2`(카드·간편결제 파랑) 4개는 **제3자 브랜드 마크**다. 회색으로 칠하면 어느 결제수단인지 못 알아본다. 팔레트 규칙에서 제외하고 원본 색을 유지한다. 등급 표시가 아니므로 규칙 취지에도 어긋나지 않는다.

### 판단 보류 — `#070428`

Splash·대시보드 등 12개 화면에 40개 노드로 쓰인 진남색이다. 상태바·다크 배경으로 보이고 등급 표시가 아니다. 해당 화면을 만들 때 실제 역할을 보고 `ink`로 바꿀지 유지할지 정한다.

## 적용 방법

색은 화면마다 판단하지 않는다. `tailwind.config.ts`(웹)와 `app/src/farmfi/theme.ts`(앱)에 위 팔레트만 등록하고, 화면 코드는 토큰 이름으로만 쓴다. 팔레트에 없는 hex를 코드에 직접 적으면 안 된다 — B-05 결제 로고만 예외다.
